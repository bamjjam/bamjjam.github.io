사용 안내

웹앱을 편하게 관리하기 위한 몇 가지 팁입니다.

5.1 클라우드 동기화: 집과 학교에서 각각 같은 Google 계정으로 한 번 로그인하면 이후 브라우저를 다시 열어도 인증 상태가 자동 복원됩니다. 편집창에서 입력을 멈추면 자동 저장되며 다른 기기에도 반영됩니다. 처음 로그인할 때 기존 4.0 수정은 「이 컴퓨터의 설정으로 클라우드 시작」 버튼으로 가져올 수 있습니다. Google 로그아웃 상태에서는 브라우저에만 저장됩니다.

자동 등록: GitHub 공개 저장소는 페이지 로딩 시 불러옵니다. 배포된 웹앱에는 GitHub에서 Pages 기능이 설정된 저장소만 표시됩니다.

직접 추가: 공개 API에서 보이지 않는 비공개 작업물이나 다른 웹사이트를 추가하세요. 기본적으로 주소·이름·분류는 현재 브라우저에 저장됩니다. Google 로그인 중이면 추가한 주소도 본인만의 클라우드에 자동 저장됩니다.

수정·숨김: 각 카드 오른쪽 위 연필을 눌러 이름, 과목, 실행 주소를 고치거나 숨길 수 있습니다. 별표는 즐겨찾기입니다.

추가 웹앱: 카드의 연필을 눌러 이름 | 파일명을 한 줄에 하나씩 입력하세요. 예: 교사용 | teacher.html. 파일들은 같은 저장소에 업로드하면 됩니다. QR코드 만들기로 학생용 접속 QR을 크게 표시하거나 PNG로 저장할 수 있습니다.

백업: Google 로그인으로 자동 동기화할 수 있습니다. GitHub catalog.json 발행은 4.0 이전 버전을 위한 선택 기능입니다. 3.0의 수정 정보는 같은 브라우저라면 자동으로 불러옵니다. 다른 PC의 예전 설정은 설정의 백업 불러오기로 병합하거나 이전할 수 있습니다. 공개 사이트 HTML에 개인 정보나 액세스 토큰을 넣지 마세요.

주의: Pages 설정이 되어 있어도 빌드가 실패했거나 배포 주소가 다르면 실행되지 않을 수 있습니다. 그 경우 연필을 눌러 정확한 주소를 지정해 주세요.
